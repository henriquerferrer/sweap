After /sweap:demo films what a milestone delivered (quick feedback), the next step is deeper: a shareable doc (Google Doc) of the same user flows, with steps and expected results, that the developer and a domain expert helping build the product walk together to go deeper on UX.
Reuse what demo already has: the milestone's on-screen flows, and each tour's steps and assertions as the steps and expected results (checked against the shipped app, not copied from item specs, which are written against code). Add one open question per flow: 'is this how it works for you?'. The expert writes notes in the doc; a session reads them back and files each through /idea or discovered/ in their words, naming them as source.
Open: the reader needs an environment to test in (a staging URL with throwaway data, or the developer's machine in person); production is out.
