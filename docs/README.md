# docs

The written record behind sweap. Nothing here is loaded at runtime.

- **`research/`** holds decision records, one dated memo per question: what was measured, what was proposed, what hostile review killed and why. The plugin's source cites them where a design choice would otherwise look arbitrary.
- **`superpowers/specs/`** holds design specs, written before building.

Consumer projects appear as consumer A, B and C. Issue numbers after those names belong to that consumer, not to this repo.
